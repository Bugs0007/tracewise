## Post (paste as is)

I got tired of watching algorithms get explained and still not being able to write them from scratch.

So I built Tracewise. Every lesson steps through a real run of the code. You predict the next move before it happens. Then the hints fade away until you're typing the function from a blank page.

It covers DSA (all of NeetCode 150), backend, frontend, system design, AI engineering and cloud. It runs fully in your browser, no signup needed, and it's open source.

The trailer is above. If you're prepping for interviews and you're done with walls of text, try one lesson and tell me what felt off.
